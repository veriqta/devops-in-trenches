# Changelog

All notable public changes to DevOps in the Trenches will be recorded in this file.

The project uses repository release numbers to identify coherent public snapshots. A repository release does not necessarily correspond to a print or ebook edition.

## How Changes Are Recorded

Entries are grouped under:

- Added, for new public material.
- Changed, for substantive revisions.
- Corrected, for confirmed factual, editorial, link, or formatting corrections.
- Removed, for withdrawn public material.
- Security, for public notices about security-sensitive repository changes.

Minor maintenance that does not affect reader understanding may be omitted.

## 0.1.0, 2026-10-03

### Added

- Initial public repository structure.
- Master table of contents with 12 parts, 63 chapters, and five focused sessions per chapter.
- Book introduction, *The Work Begins Where the Diagram Ends*.
- Reader guide with complete, problem-based, team-study, and role-based reading paths.
- Publication information, copyright notice, disclaimer, source policy, and citation guidance.
- Book directory README and reader navigation.
- Root README describing the public companion repository.
- Copyright and use policy.
- Contribution guidelines.
- Code of Conduct.
- Directories for samples, checklists, resources, errata, media, and repository templates.

### Changed

- Organized the book around the operating life of a production system rather than around individual tools.
- Added explicit coverage of service ownership, operability, production readiness, reproducible builds, distributed-systems failure, restore engineering, and human accountability for AI-assisted operations.
- Separated overlapping domains, including platform engineering and Kubernetes governance, enterprise identity and pipeline credentials, reliability engineering and incident operations, and backup completion and recovery evidence.

Confirmed corrections also appear in [errata/corrections.md](errata/corrections.md) when they affect released content.
